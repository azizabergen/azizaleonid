# Свадебное приглашение

Файлы сайта для публикации через GitHub Pages.

## Публикация

1. Распакуйте архив.
2. Загрузите `index.html`, `restaurant.png` и папку `assets` в корень репозитория GitHub.
3. В настройках репозитория откройте **Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.

Главная страница — `index.html`. Изображения и музыка должны оставаться в папке `assets`, фото ресторана — рядом с `index.html`.
